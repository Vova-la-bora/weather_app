# weather_app

Лабораторная работа: мобильное приложение «Погода» на Flutter.

Приложение определяет город по геолокации и показывает температуру и состояние погоды (OpenWeatherMap) с анимацией Lottie.

## Пакеты
- `http` — запросы к API
- `geolocator` — текущая позиция
- `geocoding` — город по координатам
- `lottie` — анимации погоды

## Запуск
```
flutter pub get
flutter run
```

Нужен ключ OpenWeatherMap (https://openweathermap.org/api).
